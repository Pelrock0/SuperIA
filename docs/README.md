# Project Documentation

## Structure

- \prd/\ - Product Requirements Documents
- \dr/\ - Architecture Decision Records
- \plans/\ - Technical Implementation Plans
- \pprovals/\ - Approval records for features

## Workflow

1. Feature request generates PRD in \prd/\
2. Technical plan created in \plans/\
3. Architecture decisions documented in \dr/\
4. Approvals stored in \pprovals/\

All documents use Markdown format for version control and easy reading.
