Resumen ejecutivo

Visión
  • Superia une listas compartidas, historial de compra e IA sin exponer la API key en cliente.
  • El documento define 45 historias en 11 épicas, de landing pública a administración SaaS.
  • Frontend React sigue pantallas Google Stitch vía MCP; guía técnica fija Laravel, MySQL y JWT corto.
  • IA y precios usan pipelines por capas con límites freemium y validación JSON en servidor.
  • La cabecera del markdown cita FastAPI y Railway; la tabla de stack en guía técnica prioriza Laravel y jobs Laravel.
  • Conectar con el dashboard de KPIs en la siguiente diapositiva.

Guía técnica para agentes

Stack · Stitch · IA
  • Stack: Laravel, React, MySQL Dinahosting; JWT 15 min y refresh 30 días.
  • Stitch: conectar MCP antes de generar cada componente React del mapa HU.
  • Claude: solo servidor; JSON validado; un reintento si el parseo falla.
  • Precios: historial → dataset estático → Open Food Facts → Claude como último recurso.
  • Jobs: resumen semanal HU-505 con jobs Laravel según esta guía.
