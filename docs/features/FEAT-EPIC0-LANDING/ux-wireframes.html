1. UX Proposal

User Actions

  • Visitante ve la landing y entiende la propuesta de valor sin scroll
  • Visitante rellena formulario de waitlist (nombre*, email*, companion opcional)
  • Visitante lee la política de privacidad (enlace visible, no solo footer)
  • Admin gestiona waitlist desde panel Backpack (tabla, filtros, invitar, exportar CSV)

Feedback & Confirmations

  • Formulario: estados de carga ("Enviando..."), éxito (posición en lista), error (validación, rate limit)
  • Email: confirmación con posición aproximada
  • Admin: alerta flash tras invitar usuario

Error Handling

  • Validación inline (email formato, nombre requerido)
  • Email duplicado: mensaje genérico de éxito (no revelar existencia)
  • Rate limit 429: mensaje amigable "Inténtalo más tarde"
  • Error genérico 500: "Ha ocurrido un error"

UX Risks

  • Carga >2s en móvil: mitigado con Vite build + Tailwind purge + lazy loading
  • Formulario sin feedback visual: mitigado con estados disabled/loading

4. Annotations

Design System: Stitch "Editorial Intelligence"

Colores principales: Deep Teal #003E54 (primario), Emerald #10B981 (acento). Material Design con Tailwind CSS. Light mode. Tipografía sans-serif system.

Responsive: Mobile-first

Landing responsive en 3 breakpoints: mobile (375px), tablet (768px), desktop (1440px). Features grid pasa de 3 columnas a 1 en mobile. Formulario centrado max-width 480px.

Performance: Carga <2s en 3G

React SPA con Vite build + Tailwind purge. Lazy load PrivacyPage. Sin scripts de terceros, sin analytics, sin cookies de tracking.

Admin: Backpack CRUD existente

El panel admin usa Backpack CRUD (ya instalado). No se diseña UI custom para admin. Backpack proporciona tabla, filtros y acciones. Se añaden botones custom "Invitar" y "Exportar CSV".

Accesibilidad

Labels asociados a inputs con htmlFor/id. Roles ARIA en alertas de error. Contraste WCAG AA en textos principales. Focus visible en inputs y botones.
